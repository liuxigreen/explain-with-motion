# 文字驱动知识片的写法

## Vibe 知识大赏文案五步法

1. **选题找反差和分享理由。** 先写“多数人以为……”和“这个题能具体解释……”。再问读完会想发给谁、为什么。生活困惑、真实两难和新证据都可以成为入口。热点只有能帮助理解时才写进去。
2. **开场先制造一个具体的认知冲突。** 把前三秒作为短片试写目标，前五秒尽量亮出主问题，按阅读速度和叙事需要调整。《信息论》先让观众补熟悉的诗句，再追问为什么几乎人人都猜得到。《长安》让计数和关门规则同时出现。写完应能说清观众此刻在等哪个答案。
3. **把概念翻译成观众能体验的事。** 先让人猜、比较或做选择，再指出真正改变结果的变量，最后用可核实的实验或历史案例补证。长片拆成多个小问答，每段加入一条新证据或一种新解释。例如从熟悉诗句的可预测性讲到冗余，再用噪声案例推进问题。保留理解所需的术语，给重要转折留读时。
4. **从知识回到生活。** 结尾写清这个发现改变了什么判断。《幸存者偏差》把统计解释变成可带走的提问：“没回来的，在哪里？”生活哲学片可以进一步给出有条件的生活判断。科学片若延伸为人生启示，明确这是类比，别把理论直接当人生定律。安全科普可收在清楚准确的行动判断。
5. **用阅读节奏打磨全文。** 试读开头、证据、转折和最后一句。删背景套话，让关键短句有停留。正文只留推进理解的句子，出处与限定条件放在对应画面附近。初稿通过后再安排出字、动作和音乐节点。历史年代、术语与数字先核实，声音节拍从实际音轨确认。

起稿交付依次写出 **一句选题反差 → 一段开头 → 若干小问答及证据 → 一句可复述的结尾**。正文定下来后，再给每段标出哪些信息留在屏幕文字，哪些交给画面展示。

依据22条全时长半秒OCR候选，结合既有镜头记录归纳。秒点是证据定位，不是精确出字时点。下表描述片中如何组织材料，数字、引文与科学史实用于新稿前另核来源。第7701225689332206911条按片内内容称“乒乓与等待回复”。

| 案例 | 写法和证据定位 |
|---|---|

| 运气 | 5秒问运气能否计算。用骰子、未完赌局、抛硬币和落珠递进，每段让随机性变得更可见。124秒回收“有了形状”。 |

| 幸存者偏差 | 先用猫的反常统计制造疑问，再用飞机换案例、保留同一个问题。139.5秒把答案变成以后可问的一句话。 |
| 知识诅咒 | 先演聊天误读，14.5秒附近亮概念，再以敲歌实验让读者看见说者和听者的信息差。94秒起给具体示范。 |
| 烽火 | 先教白天/夜间与火炬数量规则，58秒附近用“没看见火”翻转预期。192.5秒把火与驿马拆成告警与详情。 |

| 道家 | 3.5秒左右用握沙的反例讲“越用力越糟”，22.5秒再用水和草的动作说明。多个比喻共享同一论点。 |
| 闪电 | 先给反常观察，5秒承诺慢放，沿可见的放电阶段推进，126秒把漫长解释折回现实一瞬。技术数值另核。 |

| 龙脉 | 开头挑战旧说，39.5秒把争论落到可计算的高程，再沿两滴水去不同方向，153秒把问题交给观众家门口。 |

## 拆开钩子、论证和落点

钩子是一项阅读承诺。逐片记录第一眼看见什么、观众会追问什么、首个答案在哪一段、最终如何兑现。标题、首屏和第一个动作可以分别承担不同任务。以下时间是已识别的定位点，首次答案的准确边界仍须按连续正文校核。

| 钩子 | 让观众追问 | 兑现方式 |
|---|---|---|
| 规则加临界点 | 《长安》鼓数逼近关门，我来得及吗 | 先让计数兑现一次关城门，再扩到坊门，继而落到个人后果 |
| 反常证据 | 《幸存者偏差》约14.5秒的统计为何反常 | 检查谁进入了样本，用飞机再检验同一种推理 |
| 参与式问题 | 《信息论》我能猜到下一句吗 | 先给观众预测体验，再用冗余解释这个体验，结尾再让观众填空 |
| 熟悉困境 | 《知识诅咒》的聊天误会为何发生 | 把熟悉的一幕变成可比较的信息差，用实验与实例补证 |
| 体验反差 | 《道家》握紧沙子为什么反而失去更多 | 先让比喻可见，再讲这个比喻照亮的处境及边界 |
| 身份代入 | 《玉玺》如果我就是玉玺，接下来谁会得到我 | 用同一个物件贯穿不同年代，最后把争夺转成价值判断 |
| 过程承诺 | 《闪电》约5秒承诺把瞬间放慢，里面到底有什么 | 让每一阶段都出现新状态，最后回到开头的现实时间尺度 |

钩子之后检查四层。**生活场景**负责让观众认出自己的经验，例如听了三个月美剧仍离不开字幕。**矛盾**负责让他觉得原有解释不够，例如投入增加，短期表现仍像原地踏步。**解释或证据**说明为什么，例如《持续努力》约92秒转入解题实验。**落点**让观众重新理解开头，例如约170.5秒再一次关字幕。每层是否成立，要看文案本身，即使把画面和音乐拿掉也能逐句讲通。

| 正文类型 | 怎么往下写 | 易写错的地方 |
|---|---|---|
| 生活哲学 | 具体处境 → 行动与结果的矛盾 → 换一个比喻验证看法 → 给有条件的生活判断。《道家》用握沙、水与草切换观察角度。 | 把一个比喻当成普遍规律，或用金句替代推理。 |
| 科学机制 | 熟悉现象 → 做一次预测或对照 → 揭示变量 → 给概念命名 → 回原问题检验。《知识诅咒》从误读走向信息差。 | 先背定义、堆实验数字、把单项研究推到所有情况。 |
| 历史叙事 | 人物目标 → 规则与后果 → 例外 → 扩到制度或历史变化 → 回收人物处境。《长安》约42.5秒用例外重新打开问题。 | 用年代和人名充当推进，混淆律文、小说与示意画面。 |
| 心理与成长 | 具体的失败或内心话 → 给观众原解释 → 引入另一种解释 → 给可观察的变化。《U型》用犯错类型的变化表现学习进程。 | 给人物贴诊断标签，或许诺人人都会获得同一结果。 |

长片逐段填表时，每段写清：**接住哪一个问题、这一段的新增信息、用什么证据、答案的边界、下一段为何成立**。节奏可用句式变化实现：开头短句交代冲突，正文用具体名词和动词承载证据，转折处单独停一拍，结尾回收前文关键词。逐片复核应标记首个答案、再次提问和结尾兑现的秒点，并明确哪些只是 OCR 候选。

## 写完文案再定镜头

1. 用一句话写出观众会问什么，再写一句准确答案。选一个能让观众亲自遇到问题的情境。机制题可让他猜或看对照，历史题可让他面临一项有后果的选择。
2. 把长稿拆成阶段性问答。每段先兑现上一段承诺，再引出由这个答案产生的新问题。比如烽火先回答“怎么传”，再问“没传来意味着什么”，最后分清告警和详情。不要靠连续抛问把答案拖到末尾。
3. 每换一个案例，写清它提供了哪一项新证据。只换布景却重复结论的例子可以剪掉。图表数字用于比较，出处短注贴在对应结论上。
4. 按“主句、图注与数字、画面动作、证据”四列改稿。一行只承担一个新的意思。能直接看见的变化交给动作。文字保留规则、因果、数字含义和转折。用连续计数给压力，用不同状态给结果，静音时也能读懂。
5. 结尾复用开头的同一个物件、问题或动作，赋予它新的解释。想让观众带走一句话时，把它写成可复述的判断或问题。

汽车安全示例。先给“车停了，人还在向前”这一幕，再用同机位两个假人回答“安全带改变了什么”，最后用气囊补充说明防护协作。先定好这三句各自的任务，再给每句话安排可见证据。

本页是跨片首轮写法归纳。22条机器识别均有落盘，小字、快速文字与全文阅读顺序仍需原帧校对。无需等完整逐字校对才试用已明确的结构，新增具体事实应独立核验。
