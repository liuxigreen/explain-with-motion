# 长知识视频的文案拆解

旧逐片报告已有事件线和部分字幕观察。系统的文案蒸馏需要单独建档，覆盖口播和屏幕文字，并保留时间码和原片校对状态。

## 两个可以先复用的开头

- 长安宵禁。用户分享文案用“一千下”设规则，用“第九百下”和“离家三条街”把规则变成眼前难题，再问“你怎么办”。写新题时，先让观众知道什么时候必须做决定，以及错过会怎样。数字必须有来源。
- 知识诅咒。旧报告 0–11 秒先给手机消息和误读，12–16 秒才亮题，接着进入敲击实验，用预测和实际的落差回答前面的困惑。新题也可先给熟悉的情境，再让反例或证据改变观众的解释。

## 逐片怎么拆

从已有音轨获取带时间戳的逐字稿，口播、画面字、画面动作分列。ASR/OCR 出来的数字、人名、术语和断句须对照原片。逐段记录观众此时想知道什么、给了什么新信息、证据是什么、下一句为什么值得听、哪一帧兑现承诺。标记首次交代、重复、转折、反例、阶段性答案和结尾回收。只有片内数据或叙述时，分别记录作者说法和已验证事实。

汇总时区分故事题、机制题和观点题。每类选多个案例比较开场长度、首次答案何时出现、中段如何重启注意、结尾回收哪个承诺。使用可复用结构和少量有据例子，避免照抄长稿。

## 写新片

先写一句观众问题和一句准确答案。每段兑现一个小问题，用新证据或新状态自然引出下一个。剪掉不能改变理解的重复说明。无解说片把一部分句子交给动作，屏幕文字保留角色、约束、结论等画面难表达的内容。用静音试看核对问题、过程和答案能否连成一条线。
