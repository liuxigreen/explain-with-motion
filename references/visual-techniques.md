# 22 条参考片的技术解剖与制作卡

用于从参考画面制定镜头规格。先选[图集](reference-gallery.md)里的相关案例，再按镜头需要选卡。卡里的做法是可试制的实现，参考秒点说明能观察到什么。

## 如何使用机器统计

来源为 rea-video 无 VLM 模式的 22 份 `breakdown.json`、逐片报告和《技术解剖-22条》。用既有原片图集、连续帧记录和独立 OCR 作交叉参考。每条记录可分成画面观察、机器候选、制作假设三种证据。实际渲染并查看之后再标记实现已验证。

| 观察或测量 | 制作上怎么用 |
|---|---|
| 402 个检测镜头，扣除 22 个片首标记后有 380 个转场候选。叠化 171、硬切 139、闪白 35、跳切 22、淡入淡出 9、擦除 4。《长安》占 38 个叠化候选。 | 先判断画面是不是同一对象跨地点、同条件对照或章节断开，再选转场。统计供定位，局部复核连续帧，成片不用配额。 |
| 检测器将元素变化标为出现、变化、消失，并估计瞬时、匀速及各类缓动。部分镜头被标为固定。 | 制作时间轴可沿用这组事件词。固定机位可以让变化留在对象内部。进场、运动、停住分别写时点，原片的精确曲线、动画实现及机位占比仍需验证。 |
| 原报告按区域统计疑似文字与图形框，单独的 OCR 批次有文字候选。 | 把叙述句、数值、物件标签、出处分配给不同图层。判断某层位置时看图并核读。无需让每屏都有顶、中、底三层。 |
| 像素测量补篇在三片前六镜首尾帧取样。画面亮区和相对冷暖可以比较。 | 用局部裁片比较亮区、背景和材质。灯位、灯数、光比、是否做过调色都属于候选解释。比较时可遮掉字幕以减少干扰。 |
| 制作类型、工具推荐、节拍及音效均含自动分类。 | 将 Remotion 或图生 3D 等建议视作备选实现。音效和节拍用实际音轨核对，相同 BPM 不能识别同一首曲目。 |

## 先写一份可画出来的风格规格

选一个主参考和一两个对应局部问题的辅助参考。用镜头截图和时间标明构图、占幅、空间层次、物件比例、材质颗粒、主光与环境光、文字字级和出字方式。写清该保持的规则，以及可以随故事换掉的物件和地点。暗色调可参考《长安》，纸白与墨色可参考《道家》22.5 秒。颜色的含义按单片保持一致。

从无字帧检查远看是否先见主体，再从原尺寸局部检查微纹理、接触边和遮挡。把发光、纹理、色调映射、噪点当成独立层。需要调观感时，先修体量与受光，再调后期强度。

## 制作卡

### 地形与实体场景

- **何时用**。地貌决定路线、遮挡或距离，器物的厚度和空间关系本身就是信息。
- **画面证据**。《烽火》58 秒和 192.5 秒的地形几乎铺满画幅。山脊和沟谷保持明暗层次，路线在表面上发亮。《长安》3.5 秒的门洞、人物和鼓用占幅区别角色与设施。[原片图集](reference-gallery.md)
- **做法**。Three.js 用高度场或实体网格建立地形与物件，路线采样同一高度函数，并给微小离面偏移。用相机视差展示前后层次。为人物与地面、床与地面、器物与桌面设置实际接触和阴影。先试场景深度、镜头俯仰、主体占幅，再决定细节密度。
- **验收**。关键道具的尺度有参照，路线随相机贴地，背景轮廓退后，主事件可辨。真实地图和示意地形分别标注。

### 表面颗粒、光影与空间

- **何时用**。画面需要体现湿石、纸面、铜器等质地，或由明暗引导观众去看一个动作。
- **画面证据**。《长安》3.5 秒暖亮集中于门洞与火点，106.5 秒暖色聚于小光源周围。两帧支持局部亮区的比较，灯光配置仍需试制。[原片图集](reference-gallery.md)
- **做法**。以 Three.js 的材质贴图、粗糙度、凹凸和接触阴影做出表面。颗粒通过 UV 或世界坐标随地面缩短并被前景遮挡。按用途另加空间尘粒或屏幕颗粒。给主光明确的影响范围，用环境或轮廓光保住暗部形体。可在[雨巷漏壶](../examples/browser/src/scenes/night-clock.js)看石板、铜器和冷暖切换，在[暗室窗影](../examples/browser/src/scenes/window-light.js)看投影随光源运动。
- **验收**。看原尺寸裁片和动帧。石板微纹理不能随屏幕游走，铜与木的高光应有差异。暗处仍能分辨对象边缘，亮处保留需要阅读的纹理和字。

### 锚定文字和数字

- **何时用**。同屏同时出现叙述、计数或物件解释。数字变化本身承担规则和结果。
- **画面证据**。《长安》3.5 秒左上正文、右上计数和场景同屏。《信息论》74.5 秒的读数、刻度、正文分层。图集能对照字级与位置。出字起止需看连续帧。[原片图集](reference-gallery.md)
- **做法**。Canvas 单独绘制屏幕正文。图注以对象的世界位置投影到屏幕，先给偏移与安全区，再做避让。数字、计量单位和图形的变化共用事件；必要时分成固定字位和滚动数字。正文的逐字出现、标签的整块显现与标题扫出可按功能试用。
- **验收**。变化后仍有完整句读时。机位变化时标签跟着正确对象，正文不乱跳。细字在实际目标画幅可读，颜色之外仍有位置或文字能区分状态。

### 对象进场、状态变化与反馈

- **何时用**。变化发生在一个已经建立的场景里，例如倒计时、触发开关或表格变色。
- **画面证据**。《长安》5–7 秒的计数、亮点、范围圈和坊界依次变化。约 5.7 秒达到计数结果，随后范围圈扩展。各层可以独立跟踪。[连续帧记录](transition-evidence.md)
- **做法**。用一条时间轴描述初态、触发、变化、反馈和停留。将读数、门扇、亮点、范围圈与文字分别建状态。可用瞬时跳变表达状态成立、匀速绘线显示进程、缓出表现落定。共享事件时点，按因果给视觉反馈安排先后。
- **验收**。固定机位看前后状态，能指出哪一个动作触发了什么。结论读完再进入下一镜。文字给规则，画面给结果。

### 粒子与路径

- **何时用**。看得见传递路径、计数、聚合或环境流动有助于解释。先定每个点代表什么。
- **画面证据**。《烽火》地形上的亮点和路径定位传递，《信息论》11.5 秒光点紧邻信息量指示。氛围、数据单位、沿路信号、事件爆散可用不同画法。[原片图集](reference-gallery.md)
- **做法**。用 Canvas 或 Three.js 的点、实例化几何和路径实现，显式控制坐标空间、起点、寿命、速度、密度、遮挡、尾迹与固定种子。用亮度和方向把信号从氛围中分开。数据粒子需要核对数量或比例。
- **验收**。关闭粒子层看主对象是否仍可辨，再打开看是否确实补充了方向、数量、反馈或空间深度。动帧中确认文字区域不被粒子持续侵占。

### 叠化、硬切与同一物件

- **何时用**。从实体到地图、从室外进室内，可借同一亮点或物件转交注意。硬切适合新问题、对照或明显尺度变化。
- **画面证据**。《烽火》约 2.13–2.5 秒从烽台交接到满幅地形，火点可追踪。中间帧同时可见新旧场景。[连续帧记录](transition-evidence.md)
- **做法**。先定旧画面留下哪个锚点、新画面在哪接住它。独立渲染新旧层，用一段明确的时间混合；正文可单独合成。做硬切时用相近的动作方向、物件位置或颜色帮助对照。闪白、遮罩和推拉按内容作用选择。
- **验收**。看转场前、中、后。叠化中主体和字不出现难读的重影，转场后观众知道还是同一个对象或地点。灯光或地形先建立，再给下一步路径。

### 事件声音

- **何时用**。用户需要音效或配乐，且落下、点亮、停顿等事件可以得到听觉反馈。
- **做法**。时间轴记录事件、对应声响、强弱和留白。按实际听辨安排同步。无口播依然可以配乐，有明确静音要求则导出静音。
- **验收**。先静音看文字和动作，再戴耳机核对声画，检查音效的起点和听感。资料里的峰值和 BPM 只供寻找候选点。
